🔌 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

GET  /signup
     └─ Renders signup page

POST /api/auth/signup
     ├─ Request: {email, username, password, first_name, last_name, role, department}
     ├─ Response: {message, verification_code}
     └─ Validation: All fields required, password strength checked

POST /api/auth/verify-email
     ├─ Request: {email, code}
     ├─ Response: {message, user}
     └─ Creates account after verification

🛡️ VALIDATION RULES
═══════════════════════════════════════════════════════════════════════════════

EMAIL:
  • Format: RFC 5322 compliant
  • Max length: 255 characters
  • Requirement: Unique in system

USERNAME:
  • Length: 3-50 characters
  • Characters: Alphanumeric, hyphens, underscores
  • Requirement: Unique in system

PASSWORD:
  • Length: 8-128 characters
  • Complexity: Uppercase + Lowercase + Numbers
  • Optional: Special characters (!@#$%^&*...)

ROLE:
  • Options: admin, tester, user, viewer
  • Requirement: Must be valid role

DEPARTMENT:
  • Options: Engineering, Operations, DevOps, QA, Security, Data Engineering, Management, Other
  • Requirement: Must be from list
