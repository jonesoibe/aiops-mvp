STEP 1: Create GitHub Repo and Push Code
─────────────────────────────────────────

cd /path/to/aiops-mvp

git init
git add .
git commit -m "Initial AIOps MVP for Render deployment"
git remote add origin https://github.com/YOUR_USERNAME/aiops-mvp.git
git branch -M main
git push -u origin main

⚠️  IMPORTANT: Make GitHub repo PUBLIC (Settings → Visibility)


STEP 2: Create Render Account
──────────────────────────────

1. Go to: https://render.com
2. Click "Sign up with GitHub"
3. Authorize and complete signup


STEP 3: Create Web Service
──────────────────────────

1. Dashboard → "New +" → "Web Service"
2. Click "Connect a repository"
3. Search: "aiops-mvp"
4. Click "Connect"


STEP 4: Configure Service
─────────────────────────

Name:              aiops-mvp
Environment:       Python 3
Branch:            main
Build Command:     pip install -r requirements_render.txt
Start Command:     gunicorn -w 4 -b 0.0.0.0:$PORT dashboard_lite:app
Instance Type:     Free


STEP 5: Add Environment Variables
──────────────────────────────────

Generate JWT Secret:
$ python -c "import secrets; print(secrets.token_urlsafe(32))"

Add these in Render dashboard:

FLASK_ENV          →  production
JWT_SECRET_KEY     →  (paste generated key here)
PYTHONUNBUFFERED   →  1
PORT               →  5000


STEP 6: Deploy
──────────────

Click "Create Web Service"
Wait for build to complete (3-5 minutes)
Status should show "Live" in green


STEP 7: Access Your App
───────────────────────

Your URL will be: https://aiops-mvp.onrender.com

Login:
Username: admin
Password: admin123

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

gunicorn -w 4 -b 0.0.0.0:$PORT dashboard_lite:app

This starts:
  • gunicorn: Production web server
  • -w 4: 4 worker processes
  • -b 0.0.0.0:$PORT: Bind to all interfaces on PORT (5000)
  • dashboard_lite:app: Load Flask app from dashboard_lite.py

Build Failed?
  → Check Render dashboard "Logs" tab
  → Look for red error messages
  → Common: requirements_render.txt not found → Push to GitHub again

Login doesn't work?
  → Admin / admin123 are correct
  → Clear browser cache and try again
  → Check Render logs for errors

App keeps spinning down?
  → Normal on free tier!
  → Use UptimeRobot (free) to keep it warm (see docs)
  → Or upgrade to paid plan ($7/month)
