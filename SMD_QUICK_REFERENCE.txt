INTERPRETATION EXAMPLES
================================================================================

Example 1: Normal Operation
Feature values:    0.45, 0.08, 0.03, 0.02, 0.00, 0.65, 0.25, 0.00, 0.02, ...
Interpretation:    - CPU: 45% user, 8% system (OK)
                   - Memory: 65% utilized (OK)
                   - No swapping, no I/O errors
Status:            HEALTHY - System operating normally

Example 2: High Memory Pressure
Feature value #6:  0.92 (92% of RAM in use!)
Interpretation:    - Almost out of memory
                   - System may start swapping to disk
                   - Performance will degrade soon
Status:            WARNING - Consider scaling or investigating memory leak

Example 3: I/O Bottleneck
Feature #12:       0.85 (disk busy 85% of the time)
Feature #13:       0.60 (many I/O requests queued)
Interpretation:    - Disk is saturated
                   - Applications waiting for disk access
                   - Slow response times expected
Status:            CRITICAL - Add faster disk or optimize I/O

Example 4: Network Issues
Feature #23:       0.05 (5% network receive errors!)
Interpretation:    - Network interface problems detected
                   - Packet loss occurring
                   - Data integrity at risk
Status:            CRITICAL - Check network hardware/cables

Example 5: Database Overload
Feature #33:       0.95 (database at max capacity)
Feature #34:       0.30 (30% of queries are slow)
Interpretation:    - Database struggling to keep up
                   - Many slow queries
                   - Need more database resources
Status:            CRITICAL - Scale database or optimize queries

QUICK DECISION TREE
================================================================================

Is Feature #6 (Memory) > 0.90?  -> CRITICAL: Memory pressure
Is Feature #12 (Disk Time) > 0.80?  -> WARNING: Disk bottleneck
Is Feature #18 (Disk Errors) > 0.0?  -> CRITICAL: Hardware failure
Is Feature #23 or #24 (Net Errors) > 0.0?  -> CRITICAL: Network problem
Is Feature #30 (Load Avg) > 0.90?  -> WARNING: System overloaded
Is Feature #32 (Errors) > 0.15?  -> WARNING: High error rate

All features normal?  -> HEALTHY: System operating normally
