🌐 AIOps MVP API
Welcome to the AIOps MVP REST API documentation. This API provides endpoints for authentication, incident management, anomaly detection, chaos simulation, and system metrics.
Base URL: https://your-deployment.onrender.com/api
🔐 Authentication
All API requests (except /login and /signup) require a valid JWT token in the Authorization header:
Authorization: Bearer <your_jwt_token>
Tokens expire after 7 days. Use the /auth/refresh endpoint to get a new token.
POST /auth/login ▼
Authenticate user and receive JWT token.
Request Body
{ "username": "admin", "password": "your_password" }
Response (200 OK)
200 OK
{ "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "user": { "id": "user_001", "username": "admin", "role": "admin" }, "expires_in": 604800 }
POST /auth/signup ▼
Create a new user account (Admin only).
Request Body
{ "username": "newuser", "password": "secure_password", "role": "operator" }
Response (201 Created)
201 Created
{ "id": "user_002", "username": "newuser", "role": "operator", "created_at": "2026-08-23T15:57:42Z" }
GET /incidents ▼
Retrieve list of incidents with optional filtering.
Query Parameters
Parameter Type Required Description
status string No Filter by status: active, resolved, acknowledged
severity string No Filter by severity: critical, high, medium, low
limit integer No Max results to return (default: 50)
Response (200 OK)
200 OK
{ "incidents": [ { "id": "INC-0042-SERVICE_A", "title": "High CPU Usage on Service A", "severity": "high", "status": "active", "created_at": "2026-08-23T14:30:00Z", "classification": "Performance Degradation" } ], "total": 42 }
POST /incidents/{id}/acknowledge ▼
Acknowledge an incident and assign to user.
Request Body
{ "user_id": "user_001", "notes": "Investigating the issue now" }
Response (200 OK)
200 OK
{ "id": "INC-0042-SERVICE_A", "status": "acknowledged", "acknowledged_by": "user_001", "acknowledged_at": "2026-08-23T15:57:42Z" }
GET /metrics/anomalies ▼
Get anomaly detection metrics and statistics.
Query Parameters
Parameter Type Required Description
time_range string No Time range: 1h, 24h, 7d, 30d (default: 24h)
Response (200 OK)
200 OK
{ "total_anomalies": 127, "critical": 8, "high": 23, "medium": 42, "low": 54, "detection_rate": 0.92, "false_positive_rate": 0.08, "avg_detection_time": 120 }
GET /metrics/system ▼
Get system health and performance metrics.
Response (200 OK)
200 OK
{ "uptime": 98.7, "cpu_usage": 42.3, "memory_usage": 67.8, "disk_usage": 45.2, "api_latency_ms": 125, "requests_per_second": 342, "error_rate": 0.02 }
POST /simulator/start ▼
Start chaos engineering simulation with injected faults.
Request Body
{ "duration_seconds": 300, "services": ["SERVICE_A", "SERVICE_B", "SERVICE_C"], "fault_types": ["cpu_spike", "memory_leak", "network_latency"], "correlation": true }
Response (201 Created)
201 Created
{ "simulation_id": "SIM-001", "status": "running", "start_time": "2026-08-23T15:57:42Z", "estimated_end_time": "2026-08-23T16:02:42Z" }
GET /simulator/{id}/results ▼
Get results from a completed simulation.
Response (200 OK)
200 OK
{ "simulation_id": "SIM-001", "status": "completed", "faults_injected": 53, "anomalies_detected": 47, "incidents_generated": 8, "false_positives": 2, "detection_accuracy": 0.94, "avg_detection_time_ms": 1250 }
